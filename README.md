# lab6

Lab 6 – Deep Learning on the Forest Cover dataset with PyTorch Lightning.

| Path | Contents |
| --- | --- |
| `lab6.py` | Final code. Defaults reproduce the best model (96.96% test accuracy); every flag needed to re-run the other experiments is exposed on the command line. |
| `report/Lab_6_-_Deep_Learning_Lab_Report.docx` | Completed lab report (generated by `report/fill_report.py` from `report/template.docx`). |
| `results.jsonl` | Configuration, test accuracy and training time of every run. |
| `runs/` | Shell scripts for the Part 3, 4 and 6 sweeps, the timed copy of the baseline used for Part 1, and the TensorBoard screenshot helper. |
| `figures/` | TensorBoard screenshots used in the report. |
| `my_logs/` | TensorBoard event files for all runs (checkpoints are not committed). |
| `baseline/` | The original baseline script and notebook. |

## Running

```bash
unzip datasets_Lab6.zip -x "__MACOSX/*"      # creates datasets/forest_cover.csv (not committed)
pip install torch pytorch_lightning torchmetrics tensorboard scikit-learn pandas
python lab6.py                               # final model
tensorboard --logdir my_logs/
```

Rebuild the report after new runs with `pip install python-docx && python report/fill_report.py`.
